# 💧 Water Supply App

A temporary Android application project for managing water supply services.

> 🚧 **Project Status:** Under Development

This project is being developed using Android Studio and Java.  
The application will gradually include features for customers and administrators to manage water supply-related services.

---

## 📱 Current Features

- 🔐 User Registration
- 🔑 User Login
- 👨‍💼 Admin Login
- 📱 Android-based user interface
- 🔥 Firebase Authentication integration
- 🎨 Basic Android UI

---

## 🚀 Planned Features

- 👤 Customer Dashboard
- 👨‍💼 Admin Dashboard
- 💧 Water Order Management
- 📦 Order Tracking
- 💳 Payment Management
- 📋 Order History
- 👤 User Profile
- 🔔 Notifications
- 🗄️ Firebase Database Integration
- 📊 Admin Management & Reports

---
